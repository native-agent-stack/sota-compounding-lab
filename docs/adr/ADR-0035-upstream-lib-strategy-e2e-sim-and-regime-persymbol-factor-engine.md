## Context and Problem Statement

While `sota-compounding-lab` previously shipped individual statistical building blocks (`ADR-0021` strategy factory, `ADR-0025` TCA parity, `ADR-0029` Hansen SPA/MCS + Conformal PID + Fixed-Share Hedge + Hierarchical EB, `ADR-0034` unified merit manifest), the ecosystem lacked a single zero-dependency core engine and live sidecar RPC surface uniting:
1. **End-to-end execution across the full 4-tier pinned SOTA upstream stack** (`Polars`/`DuckDB`/`Pandera`/`exchange_calendars` -> `VectorBT v1.2.0` plateau sweeps -> `NautilusTrader v2.0.0rc9` Rust-core `BacktestEngine` -> `hftbacktest`-parity `STOP_CHECK_BEFORE_MFE_UPDATE` queue simulation -> `statsmodels` OLS HAC + `skfolio` `CombinatorialPurgedCV` + `ml4t-diagnostic` DSR/MinTRL/WRC + `bashtage/arch` SPA/MCS).
2. **Multi-horizon soft market-situation conditioning** fusing structural cross-asset macro ratios, tactical breadth/VIX term structure, and intraday soft `H107` log-odds with a Cederburg-safe asymmetric volatility crash brake strictly capped `<= 1.0x`.
3. **Anti-overfit per-symbol factor & strategy adaptation** separating pre-wall calibrated per-symbol execution physics (RTH Long, RTH Short, BOATS 24/5 quantiles) from Hierarchically Empirical-Bayes-shrunk expectancy (`Jensen, Kelly & Pedersen 2023 JF`), Fixed-Share Hedge strategy tilts, Conformal PID stops quantized via Reg NMS Rule 612 inside `ADR-0022 <= 2.00%`, and cadence-matched protection (preventing tight intraday micro-trails from choking `DAILY_SWING` runners).

## Decision Outcome

1. **Zero-Dependency Core Engine (`src/sota_compounding/upstream_lib_strategy_e2e.py`):**
   - Registers all 4 upstream platform tiers (20 SHA-pinned upstreams) and 12 canonical strategies with fail-closed quarantine & retired-trap enforcement (`check_retired_trap_firewall`, `is_post_ant_strategy_quarantined`, `take_profit_cap_enabled = False`, `max_stop_pct <= 2.00%`).
   - Implements `classify_market_situation()` producing composite regime classifications (`BROADENING_BULL`, `NARROW_CONCENTRATION`, `HIGH_VOL_STRESS`, `CONTRACTION_RISK_OFF`, `OVERNIGHT_BOATS`, `TRANSITIONAL`), continuous soft VIX log-odds, and a Cederburg crash brake strictly inside `[0.25, 1.00]`.
   - Implements `simulate_queue_parity_e2e_bar_series()` enforcing `STOP_CHECK_BEFORE_MFE_UPDATE`, pre-wall `<= 2026-10-15` cutoff, Almgren-Chriss `1x`/`2x` impact, and cadence-matched lossless trailing stops.
   - Implements `apply_regime_conditioned_per_symbol_factors()` combining 194-symbol pre-wall execution physics, Hierarchical EB cluster shrinkage (`kappa = 25`), Fixed-Share Hedge weights, Conformal PID adaptive stops (`<= 2.00%`), 90d SEC dilution Long blocks, `ADR-0032` Trial #105 blind BOATS gap-fade short refusal, and unconditional fail-closed refusal of live-capital ports (`:4001`, `:7496`, `:8796`, `:8798`, `api.alpaca.markets`).
2. **Real Multi-Library Pre-Wall & Live Routing Runner (`scripts/run_upstream_lib_e2e_and_live_routing.py`):**
   - Executes all pinned upstream libraries natively against `700` official `XNYS` pre-wall sessions (`2024-01-02..2026-10-15`, `7,836,606` real 1m SIP bars, `0` post-wall bytes), joins live `:8787/api/scan` targets and 194-symbol pre-wall calibrations, and seals `docs/SOTA_UPSTREAM_LIB_E2E_REGIME_PERSYMBOL_MANIFEST.{json,md}` with deterministic SHA-256 (`allow_nan=False`, dimensionless, zero home paths/account IDs).
3. **Live `:8794` RTX 4090 Sidecar HTTP Endpoints (`src/sota_compounding/gpu_scoring_sidecar.py`):**
   - Adds `GET /health` alias, `GET /api/upstream_lib_e2e/manifest` (fail-closed `404` when absent), and `POST /api/upstream_lib_e2e/route_targets` (live real-time regime + per-symbol EB routing, returning HTTP `403` on any forbidden live-capital lane).

## Alternatives Considered

- **Adding heavy compiled runtime dependencies (`vectorbt`/`nautilus_trader`/`polars`) directly to `sota-compounding-lab`'s `pyproject.toml`:** Rejected — breaks `sota-compounding-lab`'s zero-dependency open-core contract (`dependencies = []`) and cross-OS portability; delegating library execution cleanly to pinned workstation `.venv`s (`meridian/.venv`, `sota-mover-ranker/.venv`, `Noesis-Carbon` `.venv-gpu-py312`) preserves zero-dependency core purity while executing 100% genuine pinned libraries.
- **Unconstrained per-symbol alpha grid optimization:** Rejected — small per-symbol sample sizes overfit noise; separating per-symbol execution physics from Hierarchically EB-shrunk cluster posteriors prevents variance explosion.
